# 로드맵

## 1단계 — 나 자신 (지금)

목표: 내 기록으로 지표를 다듬고, 조언이 실제로 토큰을 줄이는지 확인한다.

- [x] Claude Code 기록 읽기, 상대 비용·맥락·캐시 지표
- [x] 패턴 5가지: 긴 대화, 캐시 만료, 확인 왕복, 큰 도구 결과, 단일 설정
- [x] 마크다운 보고서(`--redact` 지원)
- [ ] **전후 비교**: 조언을 따른 뒤의 기록과 비교해 실제로 줄었는지 본다(같은 종류의 작업끼리)
- [ ] 주제 변화로 새 작업 경계 찾기(지금은 글자 수 기준)
- [ ] 작업 결과 반영: 되묻기·재시도·되돌리기가 많은 작업 찾기
- [ ] 모델별 달러 단가(확인된 값만)로 금액 보기
- [ ] 기간별 추이(주 단위)

## 2단계 — 팀

목표: 개인 평가가 아니라 **패턴과 가이드**로 팀 전체의 사용을 개선한다. 시작 전에 [privacy.md](privacy.md)의 원칙을 확정한다.

- [ ] 각자 자기 컴퓨터에서 돌리고 **집계 수치만** 내보내는 방식(프롬프트 글은 내보내지 않음)
- [ ] 팀 공통 CLAUDE.md·프롬프트 가이드를 만들고, 반(反)패턴("반드시 두 번 확인" 등)을 점검
- [ ] 일의 종류(코드 수정·문서·분석 등)로 나눠 비교
- [ ] 패턴별 비중 대시보드

## 3단계 — 조직
